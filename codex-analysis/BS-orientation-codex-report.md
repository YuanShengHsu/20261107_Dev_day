# 醫學中心乳房外科個管工具：講義內容分析報告

本報告僅整理提供的逐頁筆記。講義版本標示為 2022/11 初版、2025/04/15 修訂；以下價格與流程應視為講義紀錄，不能直接當成目前報價或給付承諾。(p.1)

**最重要的工具邊界：**講義確實將 `endoscopic assisted mastectomy` 以 `Self-pay` 呈現，但沒有提供該手術價格、商業保險理賠條款，也沒有提供原位癌／第一期／第二期且淋巴結陰性病人的完整適用條件。因此，工具可產出「待確認項目與文件清單」，不能只憑這份講義判定「一定可理賠」或算出完整手術總價。(p.19)(p.108)

下文「未載」表示提供的筆記沒有足夠資料；「工具建議」是依筆記設計的操作方式，不是講義原文規定。

## 2. 醫學中心乳房外科住院流程時間軸

### 2.1 門診／術前

| 步驟 | 實際作業與條件 |
|---|---|
| 確認手術排程 | 排程可能列 `Self-pay endoscopic assisted mastectomy`，另一示例完整名稱為 `Self-pay endoscopic assisted mastectomy, medium`；講義沒有內視鏡手術專屬套餐。(p.19)(p.108)(p.10) |
| 確認手術、麻醉同意書 | 本科病人通常已在 OPD 簽手術同意書並完成麻醉訪視；已有者不需重複點選對應項目。(p.11)(p.12) |
| 查既有檢驗檢查 | 檢查 3 個月內是否已有資料；講義表示已有時可不用再點，但未完整列出一般手術所需檢驗清單。(p.11) |
| 判斷是否重建 | 無重建選一般 `Pre-op`；combine PS 重建或 BS 自己重建選 combine 的 `Pre-op order`。(p.19) |
| 判斷 oncoplasty | 有找 PS 重建才選 `Pre-op(combine PS 重建)`，`oncoplasty 不算`；有做 oncoplasty 才點 `SIGN ONCOPLASTIC PERMIT`，並查 schedule。(p.10)(p.11) |
| 自費確認 | 衛教時確認自費項目，接病人時詢問 NP；術後衣等 NP 與廠商聯絡、確認型號後再開。(p.9)(p.14) |
| 復健會診 | 新手術病人接收清單列會診復健科；另一頁明確要求 `Malignant` 病人一律會診。(p.9)(p.19) |
| SLN 定位 | 標題要求 `W1 手術病人要開`，路徑為「核醫開單 → OTHERS」，依左、右或雙側選 Lymphscint 項目；W1 未定義。(p.17) |
| Clip 定位 | 標示「不常用」；路徑「放射開單 → 特別攝影 → Sonography」，紅框項目為 `SONO,GUIDE`、`SONO,target lesion`。(p.18) |
| 預約住院 | 系統「其他 → 簽床作業 → 預約住院登記」，並加入正確住院診斷。(p.97)(p.98)(p.100) |
| 假日入院準備 | 週五確認假日預簽床病人的 order 是否會開立；週末有抽血者確認 data。(p.115) |

**時間限制：**講義沒有明示一般乳癌手術必須提前幾天入院。簽床頁的「通常都是 1 晚」出現在化療／定期治療範例，不能直接當成內視鏡乳房切除的住院天數。(p.99)

### 2.2 入院日

1. 開立適用套餐，補開病人原本服用的藥物，特別確認荷爾蒙、標靶或化療藥物。(p.9)
2. 確認自費項目及病人意願，詢問 NP 後開立；Tisseel 明列於手術病人入住時詢問是否使用。(p.9)(p.14)
3. 一般 `Pre-op` 可見：`0.9% G/S 500mL STAT IVD`、BS routine、生命徵象、一般飲食、送 OR、午夜後禁食，以及依既有狀態選取的手術／麻醉／oncoplasty 同意書。(p.11)
4. 重建套餐另含 Veterin、Foley 相關醫囑；combine PS 重建需刪除 Vancomycin。(p.12)(p.19)
5. 完成復健會診；惡性病人一律會診。(p.9)(p.19)
6. 處理研究相關同意書：接病人頁寫「人體試驗同意書」印 3 份；後續頁則教學「人體資料庫同意書」，兩者名稱不能自行視為完全相同。(p.9)(p.20)
7. 人體資料庫同意書使用 VS 帳號開立並印 3 份；病人太晚到，簽完拿回科內，隔天主治醫師補簽。(p.20)
8. EXOFIN 等自費同意書依「其他功能 → 自費同意書生成管理系統 → BS」，填預估數量、列印、`esign` 簽名。(p.14)

### 2.3 手術日

| 項目 | 作業 |
|---|---|
| 送 OR | 套餐含 `Sent patient to OR`；重建套餐頻率為 ONCALL。(p.11)(p.12) |
| 重建 Foley | 重建入 OR 要放 Foley，套餐含 `On Foley’s Catheter`、`Keeping Foley Cath.& Care`。(p.12) |
| EnCor 衣物 | EnCor 病人必須有無鋼圈一般型束胸帶或術後衣，且一定帶入刀房；此要求不能直接套用到所有乳房手術。(p.13) |
| 檢體方向標記 | 各列術式均以 3 o’clock＝1 stitch、12 o’clock＝2 stitches；partial 無帶皮另標 skin side 3 stitches，simple 不帶皮／NSM 另標 nipple side 3 stitches。(p.6) |
| 術中檢體攝影 | 打 `［分機］` 申請急照檢體乳房攝影，至門診後棟一樓，依檢體標記擺位供放射師攝影；手寫另提醒確認 calcification。(p.6) |
| 特別傷口處置 | 若 VS 交代胸口彈繃、腋下夾毛巾，需開相應 order。(p.24) |

### 2.4 術後當日、D1 至出院

**講義沒有分列 D1、D2 的固定流程，也沒有乳房切除或重建的標準出院日；工具應以事件與主治醫師指示呈現，不能自行生成固定天數套餐。**(p.7)(p.24)(p.25)

- 開立 `Post-op` 套餐；主治醫師病人由 VS 自己開，其餘表列主治醫師由 R 開。(p.7)(p.24)
- 套餐含術後返病房、`On Post-GE routine`、`NPO for 6 hours`、換藥、傷口管路引流與血糖檢查；`Record drainage amount` 標示有引流管才要。(p.24)
- 止痛、抗生素、Transamin 依主治醫師分支處理，詳第 6 節。(p.7)
- 出院止痛藥帶 3 或 5 天；主任病人另列 `Cefa + Trand *3 days`。(p.25)
- 原有荷爾蒙／標靶藥在化療期間是否恢復，需詢問。(p.25)
- 確認 BS OPD，主任病人先問主任，避免太早回診而引流管仍拔不掉；原則 cancer 掛上午、benign 約下午。(p.25)
- 確認是否掛 CTC：主任病人需問是否配合化療時間；其他 VS 出院時詢問，通常不用先掛。(p.25)
- 重大傷病出院系統操作為選 Y、點選診斷，再按「認定重大傷病」；此頁未提供原位癌等各診斷的資格判準。(p.75)

- 魚油、益生菌、Vit B、B complex／Agifutol 等出現在自費處方、化療或拿口服藥／基因檢測情境，不能據此列為所有乳房切除病人的標準營養套餐。(p.34)(p.37)(p.50)(p.61)(p.62)(p.78)

### 8.2 流程與醫療內容問題

- 第 9 頁稱「人體試驗同意書」，第 20–23 頁稱「人體生物資料庫同意書」，不能自行認定為同一文件。(p.9)(p.20)(p.21)(p.22)(p.23)
- 第 6 頁 simple「帶皮」旁手寫 skin sparing，與表格欄義的關係需回原圖核對。(p.6)
- 第 17 頁 W1 未定義；第 7 頁 PM 未展開；第 25 頁 `Trand` 未提供與 Transamin 的明確對照。(p.17)(p.7)(p.25)
- 術後止痛的「套餐」包含多個藥物，但不是每位主治醫師皆相同；不能全選後視為通用處方。(p.7)(p.24)
- 回診表有各主治醫師時段，但出院頁又要求問主任、癌症原則上午，應保留主治醫師確認步驟。(p.7)(p.25)
- 第 51 頁寫首次化療不用抽血，第 73 頁寫首次化療前要抽 baseline，互相矛盾。(p.51)(p.73)
- Mvasi 首次後接化療寫間隔 6 小時，Avastin 首次後則寫 16 小時；不能因同類藥品而自行統一。(p.52)(p.66)
- Neulasta 時點有「>24小時」「24小時後」及出院後第二天建議，不能只靠日曆上的「第2天」判斷間隔。(p.34)(p.36)(p.42)

- 第 70 頁 Dorison 時間軸有先後不一致；第 69 頁又註「現不常用」，適用範圍不清。(p.69)(p.70)
- 本院 BRCA、germline／somatic 章節有重複 SOFIVA／Blood 畫面；somatic tissue 頁與實際截圖不一致。(p.80)(p.82)(p.84)(p.86)

### 8.3 工具上線前必須另查的資訊

以下皆為**筆記未提供完整答案**的項目：

1. **術式與適用性：**原位癌、第一期、第二期及淋巴結陰性病人的內視鏡切除、NSM、skin-sparing、SLNB 與立即重建適用條件；單／雙側及乳房大小對術式、價格的影響。
2. **健保：**實際申報手術碼、內視鏡附加自費範圍、重建及植入物負擔、材料給付／差額規則、原位癌重大傷病資格。
3. **商業保險：**各保單版本、手術定義與倍數、癌症及原位癌定義、住院必要性、材料與重建限額、正副本及除外條款。
4. **報價：**內視鏡手術、重建、植入物、Tisseel、EXOFIN、麻醉、病房及耗材的現行單價、必選／選配與實際用量。
5. **住院照護：**D1 檢查、重建監測、出院條件、引流量與拔管標準、傷口清潔、洗澡、異常警訊及聯絡窗口。
6. **復健與營養：**依術式區分的運動起始日、活動限制、袖套適應症、蛋白質／熱量需求、補充品與用藥交互影響。
7. **文件：**院方可提供的診斷書與手術名稱格式、費用、份數、申請時間，以及保險公司實際要求的證明。

因此，依這份講義可完成的工具核心是：**流程分支、自費品項核對、文件待辦、問題清單與部分已知價格小計**；「可理賠金額、完整自費總價、固定住院天數及個別照護處方」仍須補入經查證的資料。
